# 《土拨鼠大作战 3D》不真实设定审计报告

审计范围：`marmot-3d/` 全部源码（src/ 8308 行）与 2D 原版关键参数。
方法：逐模块核对物理积分、单位换算、生态参照值，标注文件与行号。
参照基准：旱獭（喜马拉雅旱獭）体长 50–65cm、体重 3–5kg、肩高约 0.3m；
藏狐肩高 0.38–0.45m、体重 4–6kg、极速约 50 km/h 且仅能维持数秒。

---

## 一、P0 — 明确的代码/单位错误（建议优先修）

### 1. 阵风把「加速度」当「位移」用，且只吹玩家

`src/main.js:931-934`

```js
if (env.gust !== 0) {
  const push = env.gust * env.gustDir * dt;
  controller.position.x = clamp(controller.position.x + push, -74, 74);
}
```

`env.gust` 的注释写明单位是 **m/s²**（`main.js:455`），但 `push = a × dt` 得到的是
**速度（m/s）**，却被直接加到位置上当位移。物理上少了一次 dt 积分。

- 实际效果：玩家侧向漂移的等效速度峰值 = `gustMax` = **7.5 m/s**，
  比自己的奔跑速度（6.6 m/s）还快，基本无法对抗；
- 设计意图（7.5 m/s² ≈ 0.77g 的推力）配合草地摩擦本应是可以顶风走的；
- 附带问题：风停后没有惯性，瞬停；clamp 上界 74 与控制器边界 77 不一致；
- 环境不对称：8 只狐狸、粒子、植被完全不受风影响，只有玩家被推。

正确写法（二选一）：

```js
// 方案 A：风力累积成速度，再走控制器（有惯性、可对抗）
playerWindV += env.gust * env.gustDir * dt;
playerWindV *= Math.exp(-3 * dt);          // 摩擦衰减
controller.position.x = clamp(controller.position.x + playerWindV * dt, -77, 77);

// 方案 B：保持近似手感，至少把语义改对
const push = 0.5 * env.gust * env.gustDir * dt * dt;   // x = ½at²
```

### 2. 幼狐「跃扑」的碰撞判定与视觉高度脱节

`src/main.js:976-998`（接触伤害）与 `src/entities/fox.js:350-356`（leap 高度）

命中判定只用**水平 2D 距离**（`d < reach`），不看狐狸腾空高度。
于是幼狐跃扑时：模型已飞到 1.55m 高空、从玩家头顶掠过，只要水平距离
< 1.45m 仍然判定命中——「狐狸从头顶飞过却把我撞了」。
反过来，玩家只需腾空 0.34m（`dodgeHeight`）就能免疫，判定不对称。

建议：幼狐扑击判定条件加上高度差，例如狐狸 leap > 0.8m 时水平判定半径
减半，或 `dodged` 条件改为 `airHeight > min(dodgeHeight, foxLeap * 0.5)`。

### 3. 受击击退是「瞬移」，且击退抵抗自相抵消

- `src/main.js:996-997`：受击后 `position += 1.5` 直接位移，无速度、无摩擦，
  斜坡上还会把玩家瞬推 1.5m（可能穿进岩石，靠下一帧 resolveCircle 弹回）。
- `src/entities/fox.js:650`：`kb = knockback * resist / (mass * 1.6)`，
  其中 heavy 的 resist 0.6 / mass 0.6、boss 的 0.38 / 0.38 **恰好抵消**，
  三种狐狸的实际击退距离几乎相同——「厚皮狐更稳」「首领撼动不了」
  的设计意图没有落到数值上。若想体现，应让 resist 与 mass 不再互为倒数。

## 三、P2 — 尺度与生态设定（项目已知，建议在文档中显式声明）

1. **狐狸体型约为真实 2 倍**：耳尖 0.92m vs 真实肩高 0.38–0.45m
   （`fox.js:35` 注释已承认"游戏尺度"）。连带后果：狐狸（0.92m）
   比玩家视线（0.46m）还高，第一人称下呈现「巨狐」。
   建议：在 README「物种配色」旁补一行体型对照表（游戏值 vs 真实肩高）。
2. **旱獭 1v1 打跑藏狐**：`startFleeing` 让狐狸体力耗尽夹尾逃跑
   （`fox.js:541`）。真实旱獭的防御是群居警戒 + 报警鸣叫驱离，
   单只旱獭不可能击败藏狐。这是核心玩法的权力反转，建议保留玩法，
   但在「教师说明」中明说这是策略游戏抽象。
3. **冬眠前关出现栽培作物**：玉米粒、向日葵籽、亚麻大量出现在
   野生草原场景（`ecology.js:75-84`）存疑；可辩解为「饲养条件下更杂食」，
   建议在采食提示文案里区分「野生采集 / 近人环境」。
4. **狐狸逃跑速度 8.4 m/s 快于玩家 6.6 m/s**——设定自洽，列出备查。
