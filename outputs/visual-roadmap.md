# 《土拨鼠大作战 3D》视觉完善路线图

基于对渲染器、场景、特效、HUD 与实机截图的全面检查整理。
分四层：**已实现（本次）→ A 零风险低成本 → B 中等回报 → C 大工程**。
每项标注：做法、改动文件、工作量、风险、预期效果。

---

## 现状评估（改动前的基线）

**已有的好底子**：渐变天穹 + 地平线雾色过渡、顶点色斑驳地形、26000 株实例化草、
摄影测量远景环、远山剪影、跟随玩家的 2048 阴影、ACES 色调映射、
分层 HUD（蓄力环准星 / 状态描边 / 威胁箭头）、爪击扇形与冲击波特效。

**主要短板**（按截图观察）：
1. 画面整体发灰、平——缺云、缺太阳视觉锚点，天空是一块纯渐变；
2. 26000 株草是静止的——风吹不动，像塑料草坪，是"假"的最大来源；
3. 草地纯色无细节贴图，贴地视角近观单薄；
4. 狐狸在绿色草原里辨识度不足（体型小、同色系），全靠预警线；
5. 缺少氛围层——无尘埃/花粉/体积感粒子，世界是"干净的画面"而非"活的空气"；
6. 镜头语言单一——无 FOV 脉冲、无命中顿感反馈（受击抖动已有但轻）。

## 一、本次已实现的三个增强（零风险，已通过语法检查）

| # | 增强 | 文件 | 做法 |
|---|---|---|---|
| 1 | **天穹程序化云 + 太阳辉光** | `src/world/scene.js` | dome fragmentShader 注入 fbm 云（天球平面投影，越近地平线越扁，符合透视）+ 双频云团；辉光方向与主平行光一致 `(26,44,20)` 归一化，颜色随关卡日照色（阴天关不违和）；`update(pos, dt)` 推进漂移 |
| 2 | **26000 株草顶点风摆** | `src/world/props.js` | `onBeforeCompile` 注入顶点着色器：按实例世界位置生成相位差（每株节奏不同），只弯叶尖；共享 uniform 由单例 rAF 自更新，暂停/标题界面风照吹 |
| 3 | **常驻电影感暗角** | `index.html` + `styles.css` | `#cineVignette` 径向压边层（中心 55% 全透明，边缘极轻），z-index 16 位于状态描边(17)之下，不遮挡预警线 |

验证方式：`start-server.bat` 启动后开 `index.html` 与 `?version=dev` 两条路径各看一遍
（云/风/暗角在两条路径都生效；dev 的 GS 场景不受影响）。

## 二、A 层：零风险低成本（每个 1–2 小时，建议全部做）

| # | 增强 | 做法 | 文件 |
|---|---|---|---|
| A1 | **狐狸 blob shadow** | 每只狐脚下贴一个加法/正片叠底软圆（`CircleGeometry` + 径向渐变 CanvasTexture），`depthWrite:false`，缩放随 `leap` 升高而缩小——腾空时影子离地变远变小，**大幅提升草原中的狐影可读性**，同时免费获得"它跳了多高"的信息 | `entities/fox.js` |
| A2 | **氛围尘埃粒子** | 常驻 `Points`（~300 点，缓慢漂浮 + 微风场 + 玩家移动时的扰动），色取关卡雾色提亮。只在近身 30m 内可见。这是把"干净画面"变成"活的空气"的最便宜手段 | 新建 `systems/ambience.js`，`main.js` 挂载 |
| A3 | **镜头 FOV 脉冲** | 起跳 fov +2°、落地 -1.5° 后回弹；挥爪瞬间 fov -1°。`controls.js` 已有 `camera.fov` 逻辑， posture 的 fovNarrow 旁叠加即可，注意 `updateProjectionMatrix` 调用成本 | `core/controls.js` |
| A4 | **预警线流动充能纹** | 预警条 shader 注入沿 +Z 流动的亮纹（`fract(vUv.y * 8 - uTime)`），蓄力时纹路流向狐身——"能量在汇聚"比静态红条直观得多 | `entities/fox.js` `buildWarnIndicator` |
| A5 | **HUD 数字 tween** | 生命/储备/负荷变化时数字滚动（0.15s lerp 到目标值），低血量时血条脉冲。小动作，手感提升明显 | `ui/hud.js` |
| A6 | **低血量持续红边呼吸** | `#stateVignette` 增加 `.lowHp` 类（现有类机制的延伸），HP<30 时极慢呼吸——替代现在的周期警告音 alone | `styles.css` + `ui/hud.js` |
| A7 | **采食/驱退的仪式感** | 浆果消失时留一圈扩散光环（复用 shockwave 的 ring 原型，0.4s）；驱退成功时屏幕边缘短促金色描边——给"完成目标"一个视觉奖赏 | `systems/effects.js` |

## 三、B 层：中等工作量高回报（每个 0.5–2 天）

| # | 增强 | 做法 | 注意 |
|---|---|---|---|
| B1 | **草地细节贴图** | CanvasTexture 程序化生成细噪声 `map` + `roughnessMap` 贴到地形，近观不再单薄；草叶材质同理加叶片脉络 | 与顶点色相乘需把 `color` 调灰一档，否则整体变亮 |
| B2 | **狐狸边缘光（雾中可辨）** | `onBeforeCompile` 给狐材质注入 fresnel rim：`pow(1 - dot(N,V), 2.5)` × 毛色提亮版。第 4/7 关浓雾沙尘里狐有轮廓光，辨识度问题从根上缓解 | WebGL/WebGPU 两条路径的 shader chunk 一致，无需分支 |
| B3 | **太阳 Lens flare sprite** | 加法混合 sprite 放太阳方向（大光斑 + 沿视线轴的 2-3 个小耀斑），与 dome glow 叠加前先把 glow 的 `pow(s,220)` 项减半避免重复 | 太阳在玩家背后时不可见，正常 |
| B4 | **爪击拖尾** | viewmodel 挥爪时生成 3-4 个历史爪位残影 mesh（opacity 递减）——第一人称唯一的"自己"动作，值得加料 | 独立 viewmodel 场景内实现，不与主场景抢渲染 |
| B5 | **命中顿帧（hitstop）** | 命中瞬间全局 dt 冻结 0.04–0.06s + 命中粒子放大 1.3×。打击感的核心技巧，不是纯视觉但强相关 | 帧循环里实现，注意别让 dt 计算器失步 |
| B6 | **灌木/草丛随风整体倾斜** | A 层风摆的推广：灌木 Group 加整体 sway 旋转（±2°），草本 `Food` 叶片轻微弯 | 幅度一定要小，大了像海草 |

## 四、C 层：大工程（需充分测试，非必要不做）

| # | 增强 | 风险与成本 |
|---|---|---|
| C1 | **后处理链（Bloom / 暗角 / 色差 / SMAA）** | 三条渲染路径 API 不同：WebGPU 路径用 `three/webgpu` + TSL `PostProcessing`；经典 WebGL 路径用 `addons/postprocessing/EffectComposer`。GS 场景只在 WebGPU 路径成立。**建议只给 WebGPU 路径加 bloom，其余降级跳过**，并保持 `?webgl=1` 可强制对比。工作量 2-3 天含回归 |
| C2 | **高斯泼溅全场景接入** | README 已说明未接入原因（WebGPU 依赖 + 不能碰撞）。若做，仅作远景层，不动玩法地形 |
| C3 | **动态天气/时辰** | 需要太阳位置、光照、雾、天空色全链路参数化并按时间插值。与关卡表冲突，建议不做 |

## 五、性能预算与回归清单

- 预算线：改动后 FPS 不低于改动前 -10%。当前基线可在 HUD 右下角直接读（`N FPS · N 三角面`）。
- 风摆/云/尘埃都是 GPU 或极轻量 CPU，预期 <2% 开销；blob shadow 每狐 1 个 draw call。
- 视觉改动后必跑：
  - `node tools/smoke.cjs http://127.0.0.1:8200/`（冒烟，防渲染崩溃）
  - `node tools/test-attacks.cjs`（预警线/攻击模式回归——改 fox.js 必跑）
  - `node tools/test-posture.cjs`、`test-viewmodel.cjs`（若动 controls/viewmodel）
  - 两条路径人工过一遍：`index.html` 与 `index.html?version=dev`，以及 `?webgl=1` 强制 WebGL。

## 六、建议推进顺序

**第一批（本次已完成）**：云 + 风 + 暗角 —— 先把"世界是活的"立起来。
**第二批（A 层全做）**：blob shadow + 尘埃 + 预警流动纹 —— 可读性与氛围。
**第三批（B 层挑 2-3 个）**：优先 B2（雾中轮廓光）与 B5（顿帧）—— 直接作用于战斗体验。
**C 层**：仅在稳定版发版前评估 bloom 一项。
