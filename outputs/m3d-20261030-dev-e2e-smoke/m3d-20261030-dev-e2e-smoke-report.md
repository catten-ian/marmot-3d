## Usage and implementation

Run the full matrix with `node tools/e2e-smoke/suite.ts`. It sequentially executes local desktop/mobile and official desktop/mobile with the fixed default timings, continues after failures, and writes `suite-result.json` plus this Markdown report. For individual iteration, run `node tools/e2e-smoke/run.ts --target=local --device=desktop` and use `--load-wait-ms`, `--settle-ms`, or `--move-ms` only to shorten/adjust an exploratory run.

The runner uses only Node.js built-ins and raw CDP; there are no npm dependencies, package installation, AI/LLM calls, or API-key reads. Local mode serves this checkout only on `127.0.0.1`, with the local static server and a fail-closed request policy. Official mode visits the dev URL, allows only the site and its required published asset origin, blocks unrelated origins, and launches Chrome with proxy variables removed. It uses isolated Chrome profiles and a non-shared debugging port.
